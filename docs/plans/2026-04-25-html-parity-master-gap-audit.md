v1 of this audit leaned on agent summaries; some claims were wrong. Authoritative findings after directly reading every Flutter file + decoding HTML assets:

### 0.1 Logo — SIZING WRONG + APK LAUNCHER MISSING

**HTML source of truth** (`Growize App Design.html:124`):
- Inline `<img>` with **base64-encoded PNG**, natural size **2125×2125 px**, 58,333 bytes.
- Rendered via class `h-full w-[35%] object-cover object-center flex-shrink-0`.
- Header is `h-14` (56 px). So rendered size ≈ **56 px tall × 35% of the left cluster width (cropped, centered)**.

**Flutter current state:**
- `assets/images/arl_logo.png` = **byte-identical** (58,333 bytes) to the HTML base64 payload — same source file. ✓
- Rendered in [arl_app_bar.dart](lib/core/widgets/arl_app_bar.dart): `Image.asset('assets/images/arl_logo.png', height: 32, fit: BoxFit.contain)`.
- **Gap A (visual):** `height: 32` vs HTML's `h-full` = 56 px → logo **42 % smaller** than design.
- **Gap B (visual):** `BoxFit.contain` vs HTML's `object-cover` + `w-[35%]` — Flutter letterboxes the square logo; HTML crops it to a narrow centered strip.

**Fix:**
```dart
// ArlAppBar — replace the Image.asset call
SizedBox(
  height: 56,           // full header height
  width: 140,           // ~35% of the 400 px max-width mobile viewport cluster
  child: Image.asset(
    'assets/images/arl_logo.png',
    fit: BoxFit.cover,  // match object-cover
    alignment: Alignment.center,
  ),
),
```

### 0.2 APK launcher icon — NOT THE ARL LOGO ❗

User flagged: "this is meant for APK users."

Current state:
- `android/app/src/main/AndroidManifest.xml` → `android:icon="@mipmap/ic_launcher"`
- `android/app/src/main/res/mipmap-*/ic_launcher.png` — **all 5 densities still the default Flutter blue "F" icon** (stock scaffold).
- `pubspec.yaml` has **no `flutter_launcher_icons` config** — no generator wired up.

**Fix:**
1. Add `flutter_launcher_icons: ^0.13.1` to `dev_dependencies`.
2. Create a square logo variant → `assets/images/arl_logo_launcher.png` (1024×1024, opaque bg — transparent PNG rendered directly on Android 13+ can be clipped by system mask).
3. Configure in `pubspec.yaml`:
```yaml
flutter_launcher_icons:
  android: "ic_launcher"
  ios: true
  image_path: "assets/images/arl_logo_launcher.png"
  min_sdk_android: 21
  adaptive_icon_background: "#FAFAF7"   # cream
  adaptive_icon_foreground: "assets/images/arl_logo_launcher_fg.png"
  web: { generate: true, image_path: "assets/images/arl_logo_launcher.png", background_color: "#FAFAF7", theme_color: "#3C5152" }
```
4. Run `dart run flutter_launcher_icons` — regenerates all mipmap densities + iOS AppIcon.appiconset + web manifest icons.
5. Also update `android:label` in manifest from `"arl_app"` → `"ARL Growize"`.
6. iOS equivalent: `ios/Runner/Assets.xcassets/AppIcon.appiconset/` — regenerated by same tool.

```dart
// `arlGreen` becomes redundant — delete and fix references to use `accent`.
```
Then run `grep -rn 'ArlColors.accent' lib/` and visually re-validate every usage — several screens may have been *accidentally* correct because the code wanted gold + got gold.

## 6. Known decisions / deliberate divergences

| Topic | HTML | Flutter | Rationale |
|---|---|---|---|
| Navigation history | Custom 10-deep stack + `goBack()` | GoRouter `canPop()` + fallback-to-home | GoRouter idiomatic, same UX |
| Lucide vs Material icons | lucide | **Add `lucide_icons`** | Keep icon parity |
| Balance toggle scope | Global DOM class | Global Riverpod provider | Equivalent |
| Static map tile | Google Static Maps URL | **Same URL via `Image.network`** | Avoid google_maps_flutter bulk |
