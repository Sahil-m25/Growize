Exit Request

Route /exit
Purpose Check lock-in status & request exit
Lock-in Status Display
Field Source Type Formula
Lock-in End Date C Computed DATE investment_date + 5 years
Days Until Lock-in Expires C Computed INT (lock_in_end_date - now()).days
Is Currently Locked C Computed BOOL now() < lock_in_end_date
Exit Request Form (if locked)
Field Source Type Notes
Requested Units E Support Ticket INT User specifies quantity (submits via support ticket)
Reason (Optional) E Support Ticket TEXT Exit request reason
Business Rules
  • Exit requests must be submitted as support tickets with category = exit_request
  • During lock-in period: only available with support approval
  • After lock-in: full exit allowed
  • Partial exit possible (per-unit basis)
Buttons & Actions
