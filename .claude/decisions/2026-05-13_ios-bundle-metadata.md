# iOS bundle metadata

**Date:** 2026-05-13
**Status:** locked
**Phase:** Implement (ship readiness)

## Context
Repo previously had no `ios/` directory at all — `.metadata` listed only
the root and web platforms. To even attempt an iOS build we needed to
scaffold the platform. Distribution path for iOS still requires an Apple
Developer account ($99 / year) which the team does not currently hold;
this commit only readies the source tree so that the bundle + signing
steps can be picked up once enrolment lands.

## Decision

### Scaffolding
- Ran `flutter create --platforms=ios --org com.agresearchlabs --project-name arl_app .`
  from the repo root. This generated `ios/` with `Runner.xcodeproj`,
  `Runner.xcworkspace`, `Runner/AppDelegate.swift`, `Runner/Info.plist`,
  `Flutter/AppFrameworkInfo.plist`, asset catalogs, and a default
  `ios/.gitignore`. 46 files in total.
- `.metadata` `migration.platforms` will be regenerated by flutter on
  next pub run; left as-is.

### Bundle identifier
- `com.agresearchlabs.growize` across all six occurrences in
  `ios/Runner.xcodeproj/project.pbxproj` (Debug / Release / Profile for
  the Runner target, plus the three matching test-target entries which
  now resolve to `com.agresearchlabs.growize.RunnerTests`).

### Display name + version
- `CFBundleDisplayName` → `Growize` (lock-screen / home-screen label).
- `CFBundleName` → `Growize` (used by the OS in some chrome surfaces).
- `CFBundleShortVersionString` + `CFBundleVersion` left as
  `$(FLUTTER_BUILD_NAME)` / `$(FLUTTER_BUILD_NUMBER)` so they continue
  to flow from `pubspec.yaml` `version:` automatically.

### Permission usage descriptions
- `NSFaceIDUsageDescription` — "Used to securely sign you in to your
  investor account." Reused for biometric (local_auth) prompts.
- `NSCameraUsageDescription` — "Used to capture KYC documents and
  profile photos."
- `NSPhotoLibraryUsageDescription` — "Used to attach KYC documents and
  project photos to your account."
- `NSPhotoLibraryAddUsageDescription` — "Used to save project reports
  and statements to your photo library."
- `NSLocationWhenInUseUsageDescription` — "Used to show your nearest
  project site when you tap a location pin."
- `ITSAppUsesNonExemptEncryption` → `false` (we only use system TLS
  and standard hashing; the export-compliance question is satisfied
  with no further filing).

Copy is deliberately conservative-protective: short, function-bound,
no marketing language. App Store reviewers explicitly reject vague or
promotional permission strings.

## Distribution still requires Apple Developer

Real iOS distribution paths — TestFlight, ad-hoc, enterprise, or App
Store — all require an Apple Developer account that signs the bundle
with a provisioning profile. We have explicitly NOT:

- Set `DEVELOPMENT_TEAM` in `project.pbxproj` (left blank / no team).
- Added `ExportOptions.plist`.
- Configured automatic signing.
- Run `pod install` (which would need macOS + CocoaPods).

The scaffold lets a future macOS-side build pick up the work without
re-doing project setup. Enrolment + signing is documented as a launch
action in `docs/ops_admin_guide.md` §8.5.
